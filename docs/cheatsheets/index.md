# Cheatsheets & Runbooks

The "how do I actually do X again" notes — commands and recipes you reach for
repeatedly. Unlike guides (which explain), cheatsheets just *remind*.

Start a new one from [`templates/cheatsheet.md`](https://github.com/makualiyev/wiki-repo/blob/main/templates/cheatsheet.md)
and add it to the list below (and to `nav:` in `mkdocs.yml`).
